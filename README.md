# 🎭 JSON Masker

A technical utility for automating the masking of sensitive data during Jackson serialization.

```text
    ___  _____  ____  _   _ 
   |_  |/  ___||  _ ||  \ | |
     | |\ `--. | | | ||  \| |
     | | `--. \| | | || . ` |
 /\__/ //\__/ /\ \_/ /| |\  |
 \____/ \____/  \___/ |_| \_|
  __  __   ___   _____  _   __ _____ ______ 
 |  \/  | / _ \ /  ___|| | / /|  ___|| ___ \
 | .  . |/ /_\ \\ `--. | |/ / | |__  | |_/ /
 | |\/| ||  _  | `--. \|    \ |  __| |    / 
 | |  | || | | |/\__/ /| |\  \| |___ | |\ \ 
 \_|  |_/\_| |_/\____/ \_| \_/\____/ \_| \_|
```

## 🚀 Implementation

### Gradle (Kotlin)
```kotlin
dependencies {
    implementation("io.github.sunkir:jsonmasker:1.1.0")
}
```

### Maven
```xml
<dependency>
    <groupId>io.github.sunkir</groupId>
    <artifactId>jsonmasker</artifactId>
    <version>1.1.0</version>
</dependency>
```
